# 🚀 React Admin Dashboard

A modern, responsive, and feature-rich **Admin Dashboard** built using **React.js** and **Vite**. This project provides a clean user interface for managing products, users, orders, analytics, and settings with authentication, charts, and dark mode support.

---

## 📌 Project Overview

The React Admin Dashboard is designed to simulate a real-world administration panel. It includes authentication, dashboard analytics, CRUD operations, responsive design, and theme customization.

# 🔑 Authentication Flow

```
Signup
   ↓
Account Stored in LocalStorage
   ↓
Login
   ↓
Protected Dashboard
   ↓
Logout
```

Forgot Password updates the password stored in Local Storage.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/admin-dashboard.git
```

Go inside project

```bash
cd admin-dashboard
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```

Open browser

```
http://localhost:5173
```

---

# 📦 Build Project

```bash
npm run build
```

Preview Production Build

```bash
npm run preview
```
